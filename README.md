# Simple Interest Calculator  A simple application/script to calculate the interest earned or owed over a specific period.  ## 🧮 Formula Used The simple interest is calculated using the standard formula: **A = P(1 + rt)**  Where: - **A** = Total Accrued Amount (principal + interest) - **P** = Principal Amount - **r** = Annual Interest Rate (decimal) - **t** = Time Period (in years)  ## 🚀 How It Works 1. Enter the principal amount (initial investment or loan). 2. Input the annual interest rate as a percentage. 3. Specify the time duration in years. 4. The system calculates and displays the total interest accrued.
